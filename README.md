# AI Video Studio V0.3

Windows 11 / Python 3.14 일반 64-bit / PySide6 6.12.0. 로컬 자동 자막, 무음 후보 검토, 편집본 관리·컷 편집·MP4 출력을 지원합니다.

## 실행

main.py가 있는 폴더에서 실행합니다.

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

정확한 패키지 조합은 requirements-lock-win-py314.txt를 참고하세요. Python 3.10 안내는 폐기했습니다. FFmpeg/FFprobe가 PATH에 있어야 합니다. 현재 FFmpeg 9.0.2에서 분석과 출력 필터 파일 입력(`-/filter_complex`)을 검증했습니다.

## 화면 역할

- **미디어 보관함(왼쪽 위):** 프로젝트에서 사용하는 MP4/MOV 원본 자료와 정리 폴더입니다. 실제 파일을 이동하지 않습니다.
- **편집본 목록(왼쪽 아래):** 독립 이름을 가진 편집용 자료, 편집본, 조합 편집본을 폴더로 정리합니다. 한 폴더에 여러 편집본을 넣을 수 있습니다. 종류 칸의 ‘자료 / 편집본 / 조합’으로 구별합니다.
- **타임라인 위 탭:** 열려 있는 편집본입니다. 기존 편집본을 누르면 중복 생성 없이 열리고, ×는 탭만 닫습니다. 편집본은 목록에 남습니다. 목록에서 명시적으로 제거하는 것과 다릅니다.
- **타임라인:** 현재 편집본의 영상·음성·자막을 시간순으로 편집합니다. 자막 개수는 제목 옆 작은 글씨로 표시합니다.
- 원본 자료는 보관함 파일을 클릭해 확인합니다. 이전의 ‘선택 영상 · 원본 / 전체 영상 · 원본’ 고정 목록과 앞/뒤 순서 버튼은 제거했습니다.

## 폴더·이름·복사

각 영역의 ‘새 폴더’ 또는 우클릭 메뉴로 정리 폴더를 만듭니다. ▶/▼로 접고 펼치고 폴더 안에 다른 폴더를 만들 수 있습니다. 두 영역의 폴더는 실제 디스크 폴더 또는 새 프로젝트가 아닌 정리 정보입니다.

파일/자료/폴더/편집본의 이름을 더블클릭하거나 F2·우클릭 ‘이름 변경’으로 바꿉니다. **보관함 이름과 편집용 자료·편집본 이름은 독립적**입니다. 어느 쪽을 바꿔도 실제 원본 파일명은 바뀌지 않습니다. 편집본 목록과 그 편집본을 열어 놓은 탭은 같은 편집본 이름을 표시합니다.

우클릭에서 새 폴더·이름 변경·복사·붙여넣기·목록에서 제거·위/아래 이동을 사용합니다. Ctrl+C/V는 앱 내부 참조를 복사/붙여넣고 원본 파일을 복제하지 않습니다. 같은 영역에서 폴더로 드래그하면 해당 항목을 정리합니다. 폴더 제거는 폴더만 없애고 내용은 상위로 옮겨 보존합니다. 보관함 항목을 제거해도 이미 편집본이 사용하는 원본 참조는 유지합니다.

## 드래그로 편집 시작

- 탐색기 → 보관함: 로컬 MP4/MOV 추가. 같은 원본 경로는 원본 등록에서 중복하지 않습니다.
- 보관함 → 편집본 목록의 빈 곳/폴더: 편집용 자료로 가져옵니다. 아래 자료 이름은 독립적입니다.
- 보관함/편집용 자료 → 탭 줄 빈 곳: 새 편집본을 만들고 엽니다.
- 보관함/편집용 자료 → 기존 편집본 탭 또는 목록의 편집본: 현재 구성의 맨 뒤에 추가합니다.
- 보관함/편집용 자료/편집본 → 타임라인: 현재 편집본의 맨 뒤에 추가합니다. 편집본이 없으면 새로 만듭니다. 추가 구간으로 재생선도 이동합니다. 탐색기에서 가져오는 외부 파일은 놓은 위치에 삽입합니다.
- 편집용 자료를 여러 개 선택 → 우클릭 ‘선택 자료로 새 편집본’: 목록 순서로 구성합니다. 우클릭 위/아래 이동으로 자료 순서를 조정할 수 있습니다.
- 편집본 여러 개 선택 → 우클릭 ‘선택 편집본 조합’: 별도 조합 편집본과 탭을 만듭니다. 편집본을 기존 탭으로 드래그해 조합할 수도 있습니다.

**조합은 독립 복사 방식**입니다. 조합 당시의 컷·연결·자막을 복사하므로 원래 편집본을 나중에 바꿔도 자동 반영하지 않습니다. 원본 미디어 파일 자체는 공통 참조합니다. 원본 파일을 외부에서 교체하면 참조된 모든 편집에 영향을 줄 수 있으니 같은 경로의 원본을 교체하지 마세요.

## 프로젝트

파일 메뉴는 **새 프로젝트 / 프로젝트 열기 / 프로젝트 저장 / 다른 이름으로 저장**입니다. 프로젝트(.avsp) 하나가 보관함의 원본 연결·폴더·표시 이름과 편집용 자료·여러 편집본·자막·배치 정보를 보관합니다. 프로젝트를 열면 저장한 구성이 복원됩니다. 원본 영상은 파일에 포함하지 않고 상대 경로(드라이브가 다르면 절대 경로)를 사용합니다.

여러 프로젝트를 동시에 열 수 있습니다. 상단 프로젝트 선택 메뉴로 전환하며 각 프로젝트의 보관함과 편집본을 보여줍니다. 이미 열린 .avsp를 다시 열면 해당 프로젝트로 이동합니다. Ctrl+S는 현재 프로젝트만 저장하고 Ctrl+W는 현재 프로젝트만 닫습니다. 앱 종료 때 저장하지 않은 프로젝트별로 확인합니다. 다른 열린 프로젝트와 같은 파일로 저장하는 것은 막습니다.

프로젝트 전환은 저장하지 않은 작업을 메모리에 유지합니다. 미적용 자막 입력은 적용/버리기/취소를 먼저 확인합니다. 자막 생성 중에는 프로젝트 전환과 가져오기를 막습니다. 열린 프로젝트 목록·탭 닫기 상태·실행 취소 이력은 앱 재시작 시 자동 복원하지 않습니다. 각 프로젝트를 저장한 후 다시 열어 주세요.

이전 version 1 .avsp도 열 수 있고 저장은 임시 파일 작성 후 교체합니다. 폴더·자료·조합 종류·컷별 자막 복사 등의 선택 필드를 추가했습니다. **예전 앱으로 다시 저장하면 새 편집 정보가 소실될 수 있으므로 업데이트 앱을 사용하세요.** 최대 16MB / 원본 10000개 / 편집본 1000개 / 각 폴더 영역 1000개입니다.

원본을 찾지 못하면 보관함에서 ‘파일 찾기’를 사용합니다. 재연결은 해당 보관함 항목의 이름/폴더를 유지하지만 이전 자막·원본 참조 편집본은 재검토가 필요합니다. 실제 원본 삭제·이동·파일명 변경은 하지 않습니다.

## 무음 컷

영상 선택 → AI 무음 컷 → 무음 후보 찾기 → 구간을 확인하고 제외할 후보만 체크 → **적용 · 새 편집본 만들기**.

원본 구간 클릭은 후보 시작으로 이동해 멈추고, ‘선택한 행 재생’은 앞뒤 0.5초를 포함합니다. 기본값은 -35dB / 최소 1초 / 양 끝 0.15초 보존입니다. 0에 가까운 dB로 올리면 더 많은 구간이 잡힙니다. 상세 설정은 기본 숨김입니다.

FFmpeg가 첫 음성 트랙의 음량을 분석하며 경기의 중요도를 판단하지 않습니다. 조용한 풋살 장면도 중요하므로 후보는 모두 미선택으로 시작합니다. 적용하면 ‘무음 컷 N’을 목록과 탭에 추가합니다. 분석 창의 체크는 닫으면 초기화되고 적용한 편집본은 프로젝트에 저장됩니다.

## 컷 편집

- 블록 양 끝 드래그: 시작/종료 조절. 좁은 컷은 확대 후 조절합니다. 원본 범위·최소 길이(0.1초, 이미 더 짧은 컷은 기존 길이)·이웃 컷을 넘지 않습니다.
- 블록 가운데 드래그: 선택 컷 이동. 일반 편집은 뒤 컷 위치를 유지하고 빈 구간은 검은 화면/무음입니다.
- Shift+드래그: 뒤 컷도 간격을 유지하며 함께 움직입니다. 붙은 다음 컷을 밀며 길이를 늘릴 때 사용하세요.
- Ctrl+K / 분할: 선택 컷을 재생 위치에서 분할합니다.
- Delete/Backspace / 삭제: 선택 컷 삭제 후 뒤 컷을 삭제 길이만큼 자동으로 당깁니다. 기존의 다른 빈 구간은 유지합니다.
- 영상·음성 연결: 연결된 짝을 함께 편집합니다. 끄면 선택 트랙만 편집합니다. 없는 짝을 다시 생성하거나 강제 재배치하지 않습니다.
- Ctrl+Z / Ctrl+Shift+Z: 현재 프로젝트의 마지막 작업부터 실행 취소/다시 실행합니다. 컷·자막·배치·폴더·목록 관리·편집본 생성/제거가 같은 이력에 포함됩니다. 드래그 Esc는 적용 취소입니다. 이력은 최대 30회이며 용량 제한도 적용합니다.

Ctrl+K/Delete는 컷을 클릭한 타임라인에서 사용합니다. 입력란의 글자 편집과 목록 기본 키는 유지합니다. 상단 시간 눈금 클릭/드래그는 탐색하고, 빈 트랙은 클릭 탐색합니다. 눈금 드래그는 재생을 잠시 멈추고 120ms 간격으로 최신 탐색을 모아 적용한 뒤 기존 재생 상태를 복원합니다.

## 자동 자막과 SRT

기본 모델은 **Whisper large-v3-turbo / CPU int8**입니다. 언어와 실제 등장하는 이름·용어 힌트를 설정하고 생성한 뒤 문장·시작/종료 시간을 검수하세요. 첫 모델 사용 때 다운로드가 필요하며 이후 추론은 로컬입니다. API 키·유료 API·클라우드 음성 전송을 사용하지 않습니다. 기본 모델 캐시는 .cache/whisper이며 검증 시 STUDIO_WHISPER_CACHE로 별도 캐시를 사용합니다.

자막은 음질에 따라 오인식·누락이 생길 수 있고 검수 표시는 정확도 보장이 아닙니다. ‘조용한 구간 건너뛰기’는 기본 꺼짐입니다. 원본 검수 화면에서 자막 추가/제거·시간 조절·실행 취소와 영상 위 합성 미리보기를 지원합니다. 작은 자막(18px 미만)은 끝 조정을 막고 확대 안내를 표시합니다. 미적용 문장 입력을 보호합니다.

원본 검수 탭 및 파일 메뉴의 SRT 출력은 타임라인 또는 원본 시간 기준을 선택합니다. 편집본에 표시되는 자막은 원본에 맞춰 분할·이동해 표시하며 직접 문장 수정은 원본 검수에서 합니다. 조합 편집본의 자막은 조합 당시 복사본입니다.

## 편집본 영상 출력

편집본 탭 선택 → **파일 → 편집본 영상 출력…** 또는 상단 **내보내기** → 새 MP4 파일 지정.

여러 원본의 컷 순서·영상/음성 위치·빈 구간·선택 시 자막을 H.264/AAC MP4로 재인코딩합니다. 첫 사용 원본의 해상도(짝수 크기)와 프레임률에 맞추며 다른 해상도는 종횡비를 유지해 맞춥니다. 자막이 있으면 ‘자막 포함’이 기본 선택됩니다. 원본이나 기존 파일은 덮어쓰지 않고 임시 출력이 완료된 후 최종 이름으로 저장합니다. 취소/실패 때 임시 파일을 정리하고 처리 중 원본 변경도 확인합니다.

긴 고해상도 영상과 많은 컷은 출력 시간·메모리 사용량이 늘어납니다. 여러 원본 재생 때 파일 전환 로딩으로 짧은 지연이 있을 수 있습니다. 긴 4K 여러 파일의 장시간 편집·모든 코덱의 접합 품질은 추가 검증이 필요합니다.

## 검증과 안정성 범위

```powershell
$env:QT_QPA_FONTDIR = 'C:\Windows\Fonts'
$env:HF_HUB_OFFLINE = '1'
$env:STUDIO_WHISPER_CACHE = '캐시 경로'
.\.venv\Scripts\python.exe run_tests.py
```

테스트는 Qt/native 상태를 격리하도록 모듈별 독립 프로세스로 실행합니다. 실제 추론 검사는 캐시가 있을 때 오프라인으로 실행합니다. 자세한 기록은 TEST_RESULTS.md에 있습니다.

Windows에서는 `QT_FFMPEG_DECODING_HW_DEVICE_TYPES=','`를 기본 사용해 재생 시 소프트웨어 디코딩하며 명시적 기존 설정은 존중합니다. 시스템/드라이버 설정은 바꾸지 않습니다. 기존 4K 빠른 탐색 180회 성공 기록은 유지하되, 장시간 Qt 누적 검사 대기 문제까지 해결했다고 주장하지 않습니다.

## 원본 타임라인에서 편집 시작 · 박스 선택 (2026-11-04)

원본 확인 상태에서도 **편집 시작**, **Ctrl+K**, **Shift+블록 드래그**로 원본 구성을 보존한 새 편집본을 만듭니다. 보관함의 영상을 보기만 한 상태에서 편집본 목록이 비어 있어도 편집을 시작할 수 있습니다. Ctrl+K는 재생 위치 안의 컷을 찾아 분할합니다. 시작/끝 경계나 빈 구간에서는 분할할 수 없으므로 컷 안으로 재생선을 옮기세요.

Shift 드래그는 해당 마우스 동작이 끝날 때까지 유지됩니다. Shift를 마우스보다 먼저 놓아도 미리 보던 뒤 컷 함께 이동이 취소되지 않습니다.

타임라인의 **빈 곳을 드래그하면 선택 박스**가 생깁니다. 박스에 닿은 영상·음성 컷과 자막을 강조하며, 연결된 영상·음성은 함께 선택합니다. Ctrl을 누르고 박스를 그리면 기존 선택에 더합니다. 여러 컷을 선택한 뒤 가운데 드래그로 함께 이동하거나 Delete로 함께 제거하고 Ctrl+Z로 복원할 수 있습니다. 원본 자막만 선택한 경우에는 원본 검수와 연결되고 Delete로 선택 자막을 제거합니다. 편집본의 자막 문장은 이전처럼 원본 검수에서 수정합니다. 박스를 그리는 중 Esc는 선택 적용을 취소하고, 드래그 없이 빈 곳을 클릭하면 탐색합니다.

상단의 **프로젝트 이름**은 표시 이름 수정, **프로젝트 전환**은 열린 프로젝트 파일 사이의 작업 전환입니다. 입력 영역은 높이30px로 작게 유지하고, 설명과 입력칸 간격은 큰 창에서도 늘어나지 않습니다. 표시 이름 수정 후 Ctrl+S를 눌러야 프로젝트에 저장됩니다.

## 혼합 선택·덮어쓰기 편집 (2026-11-04)

- 프로젝트 전환은 일반 목록으로 아래에 펼쳐집니다. 10개까지 한 번에 표시하고 더 많으면 스크롤합니다.
- 클릭은 영상·오디오·소속 자막 세트를 선택하며 Ctrl+클릭은 떨어진 세트를 선택에 추가하거나 해제합니다. Alt+클릭은 기존 선택을 유지하며 항목 하나를 개별 추가/해제합니다. Ctrl+박스 드래그는 선택을 추가합니다. 트랙 위·아래 패널 빈 공간에서도 박스 선택을 시작할 수 있습니다. 시간 눈금은 기존처럼 재생 위치 이동에 사용합니다.
- 선택된 항목 가운데를 드래그하면 선택이 유지되고 영상·오디오·소속 자막이 같은 거리만큼 움직입니다. 예를 들어 0~5초 컷을 10초로 옮기면 2초 자막은 12초로 이동합니다. Ctrl+K로 분할하면 지점에 걸친 자막도 두 부분으로 나뉘어 각각의 컷에 소속됩니다. Shift+드래그는 해당 트랙에서 뒤에 있는 항목까지 함께 이동합니다. Alt로 개별 선택한 자막의 Shift 이동도 지원합니다.
- 일반 컷 이동은 덮어쓰기입니다. 목적지에 있던 컷의 겹친 부분을 제거하고 나머지를 보존합니다. 남은 조각은 원본 구간을 유지하므로 빈 곳으로 옮겨 가장자리를 늘리면 잘린 부분을 원본 범위 안에서 복원할 수 있습니다. 완전히 덮여 조각이 남지 않은 컷은 Ctrl+Z로 복원합니다.
- 세트의 자막은 컷 안의 상대 위치를 유지합니다. Alt로 자막을 개별 이동하면 독립 배치로 바뀝니다. 편집본 자막 배치는 프로젝트 저장/다시 열기, 조합, 영상 출력에서도 사용하며 원본 검수 자막은 변경하지 않습니다. 편집본 자막의 문장 수정은 원본 검수에서 진행하며, 독립 배치로 바꾼 편집본에는 나중 원본 자막 변경이 자동 반영되지 않습니다.
- 혼합 선택 이동과 편집본 자막 변경은 Ctrl+Z/Ctrl+Shift+Z로 되돌리거나 다시 실행할 수 있습니다. 편집 버튼 배치는 유지합니다.
- 앱의 빈 배경 클릭 또는 Esc는 타임라인/미디어 보관함/편집본 목록의 선택을 해제합니다. 버튼·입력칸·다른 항목 클릭은 각각의 기존 기능을 유지합니다.
- 이동 미리보기는 점선으로 놓일 위치를 표시하며, 일반 이동에서는 덮여 제거될 구간에 빗금을 표시합니다. Shift 이동은 ‘뒤 항목 함께 이동’으로 구분합니다.

## V0.3 · 대사 검색과 장면 태그

상단 **대사 검색 · 태그**에서 현재 프로젝트의 모든 편집본에 배치된 자막과 태그를 검색합니다. 대소문자를 구분하지 않으며 검색어를 비우면 전체 목록을 봅니다. 원본만 등록한 경우 먼저 편집본을 만드세요. 결과를 클릭하면 닫힌 탭도 다시 열고 **편집본 시간**으로 이동해 멈춥니다. 여러 소스, 반복 구간, 분할 자막, 독립 배치 자막은 실제 편집본 배치를 따릅니다. 원본 자막 시간으로 이동하는 기능은 아닙니다.

태그를 저장할 편집본을 열고 이름·시작·종료(초)를 입력해 **태그 저장**을 누릅니다. **현재 구간**은 선택한 컷 구간을 가져오며 컷 선택이 없으면 재생 위치부터 최대 1초를 사용합니다. 태그 결과를 선택해 삭제할 수 있고 Ctrl+Z/Ctrl+Shift+Z로 저장·삭제를 되돌립니다. Ctrl+S로 .avsp에 보관합니다. 태그는 원본 파일에 쓰지 않습니다.

**태그는 편집본의 시간에 고정됩니다.** 이후 컷 이동·삽입·삭제가 태그를 따라 움직이게 하지는 않습니다. 편집으로 길이가 짧아지면 기존 태그 시간을 재검토하세요. 조합할 때는 조합 위치만큼 시간을 더해 독립 복사합니다. 태그 이름이나 시간을 바꾸려면 기존 태그를 삭제하고 새로 저장하세요. 이전 앱으로 저장하면 태그 필드가 소실될 수 있습니다.


## V0.3 추가 · 컷 복사와 붙여넣기

편집본 타임라인의 컷을 클릭하고 Ctrl을 누른 채 다른 컷도 선택한 뒤 **Ctrl+C**로 복사합니다. 선택 컷의 영상·음성·소속 자막을 독립 복사합니다. 선택하지 않은 컷 사이의 간격은 빼고 모으며, 같은 세트 안에서 영상·음성에 따로 지정한 시간 차이는 유지합니다. 원본 미디어는 복제하거나 수정하지 않습니다. 독립 자막은 직접 선택한 경우 함께 복사합니다. 장면 태그는 컷 클립보드에 포함하지 않습니다.

- 새 결과물을 시작하려면 왼쪽 **편집본 목록 우클릭 → 복사한 컷으로 새 편집본**을 선택합니다.
- 기존 편집본에는 해당 탭을 열고 타임라인을 눌러 재생선을 원하는 곳에 놓은 뒤 **Ctrl+V**로 삽입합니다. 중간에 붙이면 걸친 컷·자막을 나누고 뒤 컷을 밀어 넣습니다. 맨 뒤에 놓으면 이어 붙입니다.
- 예: A에서 두 컷 복사 → 새 편집본 만들기 → B에서 한 컷 복사 → 결과 편집본 맨 뒤에서 붙여넣기.
- 붙여넣기는 Ctrl+Z/Ctrl+Shift+Z로 취소·다시 실행하며 Ctrl+S로 저장합니다. 새 편집본 생성도 프로젝트 실행 취소 이력에 포함합니다.
- **타임라인의 Ctrl+C/V는 컷**, **왼쪽 목록의 Ctrl+C/V는 자료·편집본·폴더**, 입력란에서는 글자를 복사·붙여넣습니다. 원본 보기에는 컷을 붙이지 않습니다.
- 편집본 목록의 폴더 안 항목은 단계당 24px 들여쓰기로 소속을 구별합니다.

## V0.3 추가 · 자막 재검토

미디어 보관함에서 원본 영상을 선택하고 **자막 재검토**를 엽니다. 자동 자막 패널에 선택된 모델·언어·이름 힌트·음성 필터 설정을 사용합니다. 편집본을 보고 있을 때는 원본 보기로 전환하며, 창의 **재검토 대상**을 확인하세요.

1. **전체 구간 / 지정 구간 / 의심 구간만** 중 하나를 선택합니다. 시작·종료는 **원본 영상 시간(초)**입니다. ‘선택 자막 구간’은 원본 검수에서 선택한 자막의 시간을 가져옵니다. 의심 구간은 외국어·반복·낮은 점수 등이 있는 미검수 자막이며 오류 확정 판정이 아닙니다.
2. **재검토 시작**을 누릅니다. 최대 30초 단위로 나누고 앞뒤 2초 음성을 포함해 **기본 설정**과 **힌트 제외** 후보를 만듭니다. 힌트가 비어 있으면 두 후보는 같습니다. 기존 기본 인식 설정 자체는 변경하지 않습니다.
3. 기존 문장과 새 후보를 비교하고 후보 선택칸에서 기본/힌트 제외를 고릅니다. 새 후보에도 의심 표시를 보여 줍니다. 행을 선택하고 **선택 구간 재생**을 누르거나 행을 더블클릭하면 기존 자막이 표시된 원본 구간을 재생하고 구간 끝에서 멈춥니다. 새 후보의 영상 위 합성 미리보기는 제공하지 않습니다.
4. 적용할 구간만 체크해 **체크한 후보만 적용**을 누릅니다. 검수 완료 자막은 기본 보호하며 보호를 해제해야 해당 구간을 바꿀 수 있습니다. 빈 후보는 기존 자막을 지우지 않습니다. 30초 경계에 걸친 기존 자막은 적용 구간 밖 부분을 보존하도록 나눕니다.
5. 적용은 원본 자막 이력에 기록하며 해당 원본 검수에서 Ctrl+Z/Ctrl+Shift+Z로 되돌리고 Ctrl+S로 프로젝트를 저장합니다. 직접 문장 수정은 기존 검수·수정 패널을 사용하세요.

작업 중 프로젝트 전환·편집을 막고 취소/실패 시 기존 자막을 보존합니다. 결과 비교 중 기존 자막·배치·프로젝트·원본 파일이 바뀌면 적용을 막습니다. 후보는 창의 임시 결과로, 프로젝트에는 **적용한 자막만** 저장합니다. 복사된 조합 자막이나 독립 배치 편집본에는 원본 재검토 결과가 자동 반영되지 않습니다.

재검토는 더 정확한 정답을 보장하지 않습니다. 같은 구간도 다른 오인식·반복·누락이 생길 수 있으므로 직접 듣고 선택하세요. 긴 전체 영상은 CPU 처리 시간이 길어집니다. 로컬 인식을 유지하며 새 유료 API나 클라우드 인식을 도입하지 않았습니다.


## 현재 편집본 표시 · V0.3 보완

탭 또는 왼쪽 편집본 목록의 항목을 일반 클릭하면 오른쪽 타임라인·탭·목록 선택을 같은 편집본으로 맞춥니다. 타임라인 위의 **현재 편집 중: 이름**과 목록의 굵은 이름으로 작업 대상을 확인하세요. 이미 열린 탭을 다시 클릭해도 목록 선택을 해당 편집본으로 맞춥니다. 폴더 안 편집본을 탭으로 열면 소속 폴더를 펼쳐 보여 줍니다. 원본 탭에서는 편집본 목록의 선택을 해제하고 **원본 보기**를 표시합니다.

목록에서 Ctrl/Shift+클릭은 복사·정리·조합을 위한 다중 선택입니다. 이때는 열린 타임라인을 바꾸지 않으며 ‘현재 편집 중’ 표시가 실제 편집 대상을 가리킵니다. 다른 탭을 일반 클릭하면 다중 선택을 해당 편집본 하나로 맞춥니다.

**타임라인의 삭제는 컷 삭제**, **왼쪽 목록의 삭제는 편집본 전체를 목록에서 제거**입니다. Ctrl+V는 현재 열린 편집본에 삽입합니다. 원본 누락이나 미적용 자막 수정 취소로 전환하지 못하면 실제 열린 편집본의 선택 표시를 유지합니다.


## 보관함·목록·드롭과 프로젝트 실행 취소

- **미디어 보관함**은 같은 원본을 한 번만 등록합니다. 예전 중복 등록 항목은 같은 원본 경로 기준으로 합치며 첫 항목의 이름·폴더를 유지합니다. 실제 파일은 복제·이동·삭제하지 않습니다. 아래 자료와 편집본은 독립적으로 여러 개 만들 수 있습니다.
- **편집본 목록의 자료 → 편집본 항목**, **자료 → 오른쪽 타임라인/타임라인 여백**은 모두 해당 편집본 맨 뒤에 추가합니다. 위 보관함에 같은 원본이 늘어나지 않습니다. 타임라인 창이 드롭을 직접 받도록 처리해 보관함 등록으로 넘어가지 않게 했습니다.
- 원본·자료·편집본·조합은 작은 아이콘과 종류 칸으로 구분합니다. 편집본을 위 보관함에 원본처럼 등록하지 않습니다.
- 보관함의 큰 ‘목록에서 제거’ 버튼은 숨겼습니다. 우클릭과 Delete는 유지합니다. 목록에 포커스가 있을 때 Delete는 목록 항목 제거, 타임라인에서는 선택 컷 삭제, 입력란에서는 글자 삭제입니다.
- 재생 제목은 영상 미리보기 왼쪽 상단, ‘영상 미리보기 · 선택 영상 시간’ 안내는 오른쪽에 표시합니다. 하단 제목 줄을 없애고 편집본 목록 폭을 260px로 넓히며 기본 아래 작업 영역을 늘렸습니다.

**Ctrl+Z / Ctrl+Shift+Z는 현재 프로젝트의 하나의 작업 순서**를 사용합니다. 자료·편집본 제거 후 내용·자막·폴더 위치를 복원하며, 생성·이름 변경·폴더 이동·복사/붙여넣기·컷 편집도 되돌립니다. 한 번의 드롭에 포함된 원본 등록과 컷 추가도 함께 되돌립니다. 보관함·편집본 목록·타임라인뿐 아니라 앱이 연 검색/재검토 등의 대화창에서도 사용합니다. 입력란에서는 해당 글자 편집의 취소가 우선이며, 파일 선택·저장 확인 같은 시스템 대화창은 자체 키 동작을 유지합니다.

프로젝트를 전환해도 각 프로젝트 이력은 분리해 유지합니다. 저장해도 이력은 지우지 않지만, 프로젝트를 닫거나 앱을 재시작하면 이력을 보존하지 않습니다. 최근 최대 30개 작업을 보관하고, 프로젝트 스냅샷의 JSON 환산 용량 약 32MiB를 넘으면 오래된 이력부터 정리합니다. 새 변경을 적용하면 다시 실행 이력은 비웁니다. 원본 파일에 대한 탐색기 이동·삭제는 앱 실행 취소로 되돌리지 않습니다.
